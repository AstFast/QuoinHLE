## 快速开始

#### 命令行(推荐)

###### 快速游戏

```bat
quoin "*.mod" --start auto --window
```

###### 指定大小

```bat
quoin "*.mod" --start WxH --window
```

#### 图形化界面

直接点击程序`quoin.exe`启动即可

[^Note]: 当前图形化界面不是正式版本，仅用于方便测试等。

## 快速编译

```powershell
#powershell 7
cd .\QuoinHLE
.\build.ps1
```
